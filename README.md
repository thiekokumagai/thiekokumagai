# Currículo — Thieko Kumagai

Vite + React + TypeScript + Tailwind (padrão shadcn/ui).

- `npm install`
- `npm run dev` → http://localhost:8080
- `npm run build` / `npm run lint` / `npm test`
- `npm run pdf` → gera `curriculo.pdf` (A4, até 2 páginas) a partir da rota `/pdf`, com Chrome instalado e Playwright

Edite o conteúdo em `src/data/curriculo.ts`.
